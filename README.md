# AI Voice Call Center — Frontend

Initial frontend dashboard built with React + TypeScript + Vite.

## Requirements
- Node.js 20+ recommended
- npm

## Run
```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Current scope
- Responsive dashboard
- Sidebar navigation
- Live calls table
- AI agent status
- Call activity chart
- Quick actions
- Mobile sidebar

Backend, authentication, PostgreSQL, WebSockets, Twilio, STT, TTS and LLM integrations will be added in later steps.
